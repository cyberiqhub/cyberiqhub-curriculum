# Linux Presentations

🌐 CyberIQ Hub – Beginner Linux Curriculum
Course Overview
The Beginner Linux course introduces students to the fundamentals of the Linux operating system, one of the most widely used operating systems in cybersecurity, IT, and software development. Students will learn how to navigate Linux environments, understand essential commands, manage files and directories, and develop practical command-line skills.
Through hands-on activities and guided lessons, students will build a strong foundation for cybersecurity, system administration, and CyberPatriot competitions.
----
# Prerequisites
- Basic computer skills
- Curiosity and willingness to learn
- Access to a computer (Windows, Mac, or Linux)
- No prior Linux or programming experience required
----
# Learning Objectives

By the end of this course, students should be able to:
- Understand what Linux is and how it differs from other operating systems
- Navigate and interact with the Linux terminal
- Understand basic Linux commands and their functions
- Work with files and directories using the command line
- Develop familiarity with Linux system environments
- Apply basic Linux skills through hands-on practice
- Build foundational knowledge for cybersecurity and CyberPatriot competitions
