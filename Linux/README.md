
# 🌐 CyberIQ Hub – Linux Curriculum

## Course Overview

The Beginner Linux course introduces students to the fundamentals of the Linux operating system. Students will learn how to navigate Linux environments, use essential terminal commands, manage files and directories, and understand basic system configurations.

Through hands-on activities and guided lessons, students will develop practical Linux skills and build the foundational knowledge needed for cybersecurity, IT, system administration, and CyberPatriot competitions.

---

## Prerequisites

- Basic computer skills
- Curiosity and willingness to learn
- Access to a computer (Windows, Mac, or Linux)
- No prior Linux or programming experience required

---

## Learning Objectives

By the end of this course, students should be able to:

- Understand what Linux is and how it differs from other operating systems
- Navigate and interact with the Linux terminal
- Understand basic Linux commands and their functions
- Manage files and directories using the command line
- Understand Linux file systems and directory structures
- Use essential Linux utilities
- Understand basic Linux system administration concepts
- Develop practical command-line skills
- Apply Linux knowledge to basic cybersecurity tasks
- Build a strong foundation for CyberPatriot competitions
