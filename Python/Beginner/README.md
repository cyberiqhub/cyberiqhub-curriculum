
# CyberIQ Hub – Beginner Python Curriculum

## Course Overview

The Beginner Python course introduces students to the fundamentals of Python programming. Students will learn how to write basic programs, understand programming concepts, develop logical thinking skills, and solve problems using Python.

Through interactive presentations, hands-on coding exercises, and final projects, students will build a strong foundation in computer science and gain the skills needed to explore more advanced programming, cybersecurity, and software development.

---

## Prerequisites

- Basic computer skills
- Curiosity and willingness to learn
- Access to a computer
- No prior programming experience required

---

## Learning Objectives

By the end of this course, students should be able to:

- Understand the fundamentals of Python programming
- Write and execute basic Python programs
- Understand variables and common data types
- Use conditional statements and loops
- Understand functions and basic program structure
- Develop logical thinking and problem-solving skills
- Debug simple programming errors
- Apply programming concepts through hands-on exercises
- Create beginner-level Python projects
- Build a strong foundation for intermediate programming and cybersecurity
