
# CyberIQ Hub – Intermediate Python Curriculum

## Course Overview

The Intermediate Python course helps students strengthen their programming skills through structured lessons, hands-on coding exercises, and problem-solving activities. Students will explore Python fundamentals in greater depth, including variables, data types, operators, conditional statements, and loops.

Through interactive learning materials and practice exercises, students will develop logical thinking, debugging, and programming skills while building a foundation for more advanced computer science and cybersecurity concepts.

---

## Prerequisites

- Basic computer skills
- Familiarity with introductory Python concepts recommended
- Access to a computer with Python installed
- Curiosity and willingness to learn
- Basic understanding of programming helpful but not required

---

## Learning Objectives

By the end of this course, students should be able to:

- Understand Python programming concepts and syntax
- Work with variables and different data types
- Accept and process user input
- Use arithmetic, comparison, and logical operators
- Understand and apply conditional statements
- Write programs using if, elif, and else statements
- Understand nested conditional statements
- Use while loops to repeat operations
- Debug common programming errors
- Develop logical thinking and problem-solving skills
- Apply Python concepts through hands-on coding challenges
- Build a strong foundation for advanced programming
