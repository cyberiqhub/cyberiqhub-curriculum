
# CyberIQ Hub – Python Curriculum

## Course Overview

Welcome to the CyberIQ Hub Python Programming Curriculum!

Our Python program is divided into three learning levels: Beginner, Intermediate, and Complex.

Students will develop programming, problem-solving, and computational thinking skills through structured lessons, presentations, hands-on exercises, and projects.

---

## Python Courses

| Level | Description | Curriculum |
|-------|-------------|------------|
| Beginner Python | Introduction to Python and programming fundamentals | [View Course](./Beginner/README.md) |
| Intermediate Python | Strengthen coding and problem-solving skills | [View Course](./Intermediate/README.md) |
| Complex Python | Explore advanced programming concepts and projects | [View Course](./Complex/README.md) |

---

## Our Goals

- Make Python programming accessible to beginners
- Develop logical thinking and problem-solving skills
- Encourage hands-on coding and experimentation
- Help students progress from basic to complex concepts
- Prepare students for future computer science and cybersecurity opportunities

---

## Getting Started

1. Start with Beginner Python if you are new to programming.
2. Move to Intermediate Python after mastering the fundamentals.
3. Explore Complex Python for more challenging topics.
4. Complete practice exercises and projects as you progress.
