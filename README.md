
# 🌐 CyberIQ Hub – Windows Curriculum

## Course Overview

The Windows course introduces students to the fundamentals of the Windows operating system. Students will learn how to navigate Windows environments, manage files and user accounts, understand system configurations, explore security features, and troubleshoot common issues.

Through hands-on activities and practice challenges, students will develop essential Windows administration skills and build the foundational knowledge needed for cybersecurity, IT, and CyberPatriot competitions.

---

## Prerequisites

- Basic computer skills
- Curiosity and willingness to learn
- Access to a Windows computer recommended
- No prior Windows administration experience required

---

## Learning Objectives

By the end of this course, students should be able to:

- Understand how the Windows operating system functions
- Navigate Windows settings and administrative tools
- Manage files, folders, and directories
- Understand user accounts and permissions
- Identify important Windows system utilities
- Configure basic Windows networking settings
- Understand Windows security features and best practices
- Use Windows command-line tools
- Troubleshoot common Windows issues
- Apply Windows administration skills to cybersecurity challenges
- Build a strong foundation for CyberPatriot competitions
